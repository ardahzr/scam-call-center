# Scam Call Center (Do Not Redeem)

Co-op comedy game where you and your friends run a scam call center and talk to AI "victims" by voice.

This repository only hosts **join-only Linux builds** for friends. The AI runs on the host's computer;
the build here needs no Python, models or API keys.

## Install (Arch Linux)
```
yay -S do-not-redeem
```
Then open Steam, run `do-not-redeem`, type the host's 5-letter lobby code and press **Kodla katıl** (Join with code).

Controls: WASD walk · E use computer · ESC leave · hold RIGHT MOUSE to talk to the victim · hold V / MIDDLE MOUSE for team voice.

Steam shows "Spacewar" while playing: until the game has its own App ID it uses Valve's public test app (480).
